# دبي الوطنية للتأمين — صفحة هبوط واتساب

صفحة هبوط بسيطة وسريعة التحميل بهدف توجيه الزوار مباشرة إلى محادثة واتساب مع دبي الوطنية للتأمين.

## التقنيات المستخدمة
- HTML/CSS ثابت (بدون إطار عمل) لأقصى سرعة تحميل.
- خط ودعم كامل للغة العربية (RTL).

## التشغيل محلياً
```bash
npx netlify dev --port 8889
```
ثم افتح `http://localhost:8889`.

## الملفات
- `index.html` — محتوى الصفحة وزر واتساب.
- `styles.css` — التنسيق البصري.
- `netlify.toml` — إعدادات النشر (نشر المجلد الجذري كموقع ثابت).
